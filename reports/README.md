# Reports and evidence

| Location | Purpose |
|---|---|

The evaluation links to compact measurements, environment/validation metadata,
and three representative plans. Generated exports and raw experimental output
are not tracked. For report selection and export options, use the
[reporting catalog](../database/reporting/README.md).
